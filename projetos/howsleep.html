HowSleep

App Android de monitoramento inteligente de sono · Em desenvolvimento

Sobre o projeto

HowSleep é um app Android que monitora a qualidade do sono de forma inteligente, correlacionando hábitos pré-sono (cafeína, telas, estresse, alimentação, exercício) com dados objetivos da Android Sleep API e avaliação subjetiva matinal.

Com uma janela de análise de 30 noites, o app gera desafios personalizados via IA e valida o sucesso matematicamente, sem depender de interação manual do usuário para detectar o sono.

Funcionalidades

  • Detecção automática de sono via Android Sleep API (sem interação)
  • Formulário de hábitos pré-sono (cafeína, telas, estresse, alimentação)
  • Avaliação pós-sono (humor, energia, qualidade percebida)
  • Análise diária por IA com janela de 30 noites
  • Desafios personalizados com prazo e validação automática
  • Modo offline com heurísticas locais como fallback
  • Dashboard de 7 noites e tendências de longo prazo
  • Modo dev com simulação de sono para testes
